# F00 — El taller Flutter

## Objetivo

Entender el ciclo `editar → analizar → testear → ejecutar` antes de construir UI.

## Práctica

1. Ejecuta `fvm flutter doctor` y explica qué valida cada sección.
2. Ejecuta `fvm flutter pub get`, `fvm flutter analyze` y `fvm flutter test`.
3. Predice qué crea `fvm flutter build web --release` y compruébalo.
4. Busca cada comando en la [documentación oficial de Flutter](https://docs.flutter.dev/reference/flutter-cli).

## Criterio de terminado

Puedes explicar la diferencia entre el SDK de Flutter, el SDK de Dart, una
dependencia de pub y un artefacto dentro de `build/`.
