# F02 — Constraints y responsive

## Objetivo

Razonar con la regla “constraints bajan, tamaños suben, posiciones las decide el
padre”.

## Práctica

1. Cambia el ancho del navegador a 360, 768 y 1200 px.
2. Localiza el `LayoutBuilder` del encabezado y predice el punto de cambio.
3. Sustituye temporalmente `Expanded` por un ancho fijo: observa y explica el
   overflow.
4. Lee [Understanding constraints](https://docs.flutter.dev/ui/layout/constraints).

## Criterio de terminado

La vista no desborda a 360 px y puedes justificar cada `Expanded`, `Wrap` y
`ConstrainedBox` utilizado.
